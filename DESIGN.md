# Design system

Geologica display type and Manrope text retain Dibsly's identity. The narrative uses charcoal, pale mineral text and a restrained amber action cue; the inspection section uses light sage and deep green. Shared site tokens remain in `src/styles/tokens.css`.

The app is the main object. A continuous metal ribbon provides architectural scale and responds to pointer lighting. A dark studio scrim preserves text contrast without covering the foreground phone. Mobile reduces the backdrop's contrast. A fine document-space line connects the narrative to the sections below and finishes in the actual period of the large footer wordmark. Near arrival, a soft connecting neck merges the circles into one shape.

One physical iPhone travels continuously between alternating text compositions. A chapter changes through a 420 ms blend between complete frames. The screen keeps its brightness throughout travel. Phone travel uses a curve with zero velocity and acceleration at its endpoints, a rising arc, banking and depth. Cursor tilt remains small enough to read. There is no second camera delay. Within an action, the phone faces the viewer.

Every action explicitly follows focus → press → native transition → held result. A large white hand approaches an amber outline on the actual screen; a pulse marks the press. Outside the phone, the control name, step number and phase reinforce the relationship. Captions follow decoded film time, not a requested frame that has not arrived. Watch/Pause and previous/next action controls let the visitor inspect the story.

The mobile scene always animates, including short portrait and landscape views. Portrait placement uses the measured heading and caption heights. Landscape uses text and phone side by side. Reduced motion and unavailable WebGL provide manual screenshot sequences.

The gallery keeps one iPhone frame while the selected native screen changes inside it. Desktop has five section choices and a short feature list. Mobile uses a native section picker and wrapping feature buttons. The entire section fits the viewport below the fixed header. Gallery entry and deliberate screen selection have restrained motion; no nested scrolling is used.

Native captures already include the status bar and Dynamic Island. The shared CSS device adds only the metal edge, glass bezel, large iPhone corner radii and side buttons. The Three.js device follows the same proportions.

Every visible press emits concentric waves from the real screen coordinate and contributes a band of particles to an extruded D. The assembled form stays behind the remaining page and responds to pointer proximity. The satin ribbon has slow independent motion and stronger cursor parallax. Navigation dots have an opaque dark tray, pale inactive markers and an amber current marker, including mobile.

The native display is a latched canvas texture. Decoder resets, loading and seeks cannot clear it. Nearly empty native loader frames are rejected; the last meaningful image remains visible until a complete successor arrives. Only a change of movie source uses the crossfade. Native frames within a movie retain their own transition.
